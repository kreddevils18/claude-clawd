# Changelog

## 0.1.0

First release.

- Mini band above the prompt and a full pane (`/clawd`).
- 15 states: wait, fail, limit-hit, burp, level-up, pat, done, edit, bash, read, think, listening, limit-warn, sleep, idle.
- Subagents appear as little Clawds in a flower meadow on the band's right edge, each in the state of what that subagent is doing; the main Clawd directs them.
- Body size follows context use (lean, round, stuffed).
- XP, levels and three hats (beanie, crown, wizard), kept across sessions.
- `/clawd` options: pat, hat, mute, unmute, hide, show, stats.
- Sound for `wait` and `burp` only, off with `/clawd mute`.
